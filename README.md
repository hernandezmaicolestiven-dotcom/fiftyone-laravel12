## 📁 Estructura del Proyecto

```
├── app/              # Código de la aplicación
├── database/         # Migraciones y seeders
├── public/           # Archivos públicos
├── resources/        # Vistas y assets
├── routes/           # Rutas de la aplicación
├── documentacion/    # 📚 Toda la documentación
├── utilidades/       # 🔧 Scripts útiles (.bat)
├── docs/             # Guías técnicas
└── scripts/          # Scripts PHP
```

## 🔧 Scripts Útiles

En la carpeta `utilidades/`:
- `resetear-todo.bat` - Resetear base de datos completa
- `arreglar-credenciales.bat` - Arreglar credenciales
- `iniciar-con-https.bat` - Iniciar con HTTPS local
