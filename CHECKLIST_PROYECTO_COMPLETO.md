## ⚠️ NOTAS IMPORTANTES

### Wompi en Localhost:
- El widget oficial NO funciona desde localhost
- Requiere HTTPS y dominio válido
- Usa `wompi-payment.html` para desarrollo
- Para pagos reales: usa Laragon, ngrok, o hosting

### Credenciales:
- **Admin:** admin@fiftyone.com / admin2026
- **Cliente:** cliente@test.com / cliente2026
- **Colaborador:** colaborador@fiftyone.com / colab2026

### Comandos Útiles:
```bash
# Iniciar servidor
php artisan serve

# Llenar productos
php artisan db:seed --class=LlenarTodoConProductosSeeder

# Resetear credenciales
php artisan db:seed --class=ResetCredentialsSeeder

# Limpiar caché
php artisan optimize:clear
```
