## ⚠️ IMPORTANTE SOBRE WOMPI

### En Localhost:
- El widget oficial NO funciona (requiere HTTPS)
- Usa `wompi-payment.html` para desarrollo
- Los pagos NO se procesan realmente

### Para Pagos Reales:
Necesitas una de estas opciones:

1. **LARAGON** (recomendado para local)
   - Descarga: https://laragon.org/download/
   - Crea HTTPS automático
   - Dominio: https://fiftyone.test

2. **NGROK** (rápido para demos)
   - Descarga: https://ngrok.com/download
   - Crea túnel HTTPS
   - Funciona inmediatamente

3. **HOSTING** (para producción)
   - Railway (gratis)
   - Heroku (gratis)
   - Hosting tradicional ($5/mes)
